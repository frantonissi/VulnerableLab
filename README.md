# VulnerableLab

**Web Application Security Laboratory**

Laboratório educacional de segurança ofensiva em aplicações web, desenvolvido para estudar, demonstrar e corrigir vulnerabilidades em um ambiente controlado.

## Sobre o projeto

O VulnerableLab é um projeto de estudo prático em cibersegurança, com foco em pentest de aplicações web e desenvolvimento seguro.

A proposta é desenvolver uma aplicação web com vulnerabilidades intencionais, analisar seus impactos e implementar versões corrigidas para compreender tanto a exploração quanto as técnicas de mitigação.

**Status:** Em desenvolvimento — fase inicial de planejamento.

## Tecnologias previstas

- **Python** — linguagem principal
- **Flask** — desenvolvimento backend
- **HTML e CSS** — interface web
- **SQLite** — banco de dados
- **Pytest** — testes automatizados
- **Docker** — isolamento do ambiente (etapa futura)

## Funcionalidades planejadas

- [ ] Sistema de cadastro e autenticação
- [ ] Integração com banco de dados
- [ ] Laboratório de SQL Injection
- [ ] Laboratório de Cross-Site Scripting (XSS)
- [ ] Laboratório de IDOR e controle de acesso
- [ ] Implementação de correções de segurança
- [ ] Testes automatizados
- [ ] Relatórios técnicos das vulnerabilidades

## Documentação

Cada vulnerabilidade estudada será documentada com sua causa, impacto, demonstração em ambiente autorizado e respectiva correção.

O projeto utilizará referências da OWASP para orientar os estudos de segurança web.

## Execução

As instruções de instalação e execução serão disponibilizadas após a implementação da primeira versão funcional.

## Aviso de segurança

Este projeto possui finalidade exclusivamente educacional.

As vulnerabilidades serão reproduzidas em um laboratório local e isolado, utilizando dados fictícios. A aplicação vulnerável não deve ser exposta à internet, e os testes não devem ser realizados em sistemas de terceiros sem autorização.
